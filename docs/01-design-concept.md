# 01. Дизайн-концепция

## 1. Позиционирование и идея

**Смысловое ядро:** «От поиска недвижимости до получения ключей».
**Поддерживающая фраза:** «Ваша задача — выбрать недвижимость. Моя — помочь грамотно пройти весь путь к сделке».

Сайт продаёт не объекты, а **процесс под контролем**. Поэтому главный визуальный приём — не галерея
дорогих интерьеров, а **маршрут**: линия, у которой есть начало (запрос), этапы и финал (ключи).
Это отличает сайт от типового шаблона агентства, где всё построено на сетке одинаковых карточек.

**Три составляющие стиля:**

| Направление | Как проявляется |
| --- | --- |
| Современный минимализм | много воздуха, максимум два акцента в блоке, нет декоративных теней и «стекла» |
| Editorial-дизайн | крупные фото в «паспарту», подписи-капшны под изображениями, асимметричная сетка, номера этапов крупной цифрой |
| Тёплый премиальный | молочный фон вместо белого, натуральные оттенки на фото, терракота как «печать» и маленькая деталь |

**Чего избегаем:** градиентных «финансовых» баннеров, синих кнопок, стоковых улыбок с ключами,
тенистых карточек-«плиток» на каждом шагу, зума при наведении на всё подряд, карусели-слайдера на первом экране.

## 2. Визуальная метафора: «маршрут сделки»

- Тонкая линия `1px` цветом `--c-line-strong` с точками-маркерами; активный этап — терракотовый.
- Номер этапа — крупная цифра `01…04` в Manrope 600, выключка по левому краю, на молочном фоне.
- Линия повторяется в трёх местах: главная (4 этапа), «Сопровождение сделки» (12 шагов),
  «Проверка недвижимости» (10 пунктов). Это создаёт узнаваемый ритм сайта.
- Второй приём — **«паспарту»**: изображение с внутренним отступом цвета `--c-milk`, подпись 13px
  под ним (`<figcaption>`). Так фото выглядят как журнальная вклейка, а не как карточка каталога.

## 3. Палитра

| Токен | HEX | Роль | Контраст (проверено) |
| --- | --- | --- | --- |
| `--c-green-800` | `#173B36` | навигация, заголовки, основные кнопки, тёмные секции | 11:1 на молочном, 12.2:1 на белом |
| `--c-green-900` | `#0F2A26` | фон футера, оверлеи | — |
| `--c-milk` | `#F5F2EC` | основной фон страницы | — |
| `--c-white` | `#FFFFFF` | карточки, поля ввода, «паспарту» | — |
| `--c-surface` | `#FBFAF7` | чередующиеся секции, фон фильтров | — |
| `--c-terracotta` | `#C68A68` | акценты: маркеры, линии, крупные цифры, hover-подчёркивания | 4.5:1 на тёмно-зелёном (только крупный текст/графика) |
| `--c-terracotta-ink` | `#A05A38` | **акцентный текст** (ссылки, метки, подсказки) | 5.2:1 на белом, 4.7:1 на молочном — AA |
| `--c-graphite` | `#242927` | основной текст | 13.2:1 на молочном |
| `--c-text-muted` | `#5C6360` | второстепенный текст, подписи | 5.5:1 на молочном |
| `--c-line` | `#E9E8E3` | разделители, обводки | — |

Правила: терракота **никогда** не используется как цвет мелкого текста в исходном `#C68A68`
(контраст 2.7:1 — ниже AA). Для текста есть отдельный затемнённый токен `--c-terracotta-ink`.
На одной секции — не более одного терракотового акцента и одного тёмно-зелёного блока.

## 4. Типографика

- **Manrope** — заголовки, интерфейс, кнопки, цифры этапов. Плотный «архитектурный» рисунок, хорошо держит крупный кегль.
- **Golos Text** — основной текст, описания объектов, блог. Спроектирован под кириллицу, 17px читается спокойно.
- Обе гарнитуры — OFL (бесплатны для коммерческого использования). Для продакшена шрифты **самохостим**
  (woff2, `font-display: swap`, сабсет `cyrillic`) — быстрее и не зависит от доступности Google Fonts из РФ.

| Роль | Шрифт / вес | Размер | Особенности |
| --- | --- | --- | --- |
| Display (H1) | Manrope 600 | `clamp(38px, 5.4vw, 68px)` | трекинг `-0.03em`, интерлиньяж 1.02 |
| H2 | Manrope 600 | `clamp(28px, 3.4vw, 44px)` | трекинг `-0.02em` |
| H3 | Manrope 600 | `clamp(20px, 2vw, 26px)` | 1.25 |
| Lead | Golos Text 400 | `clamp(17px, 1.4vw, 21px)` | 1.6, `--c-text-muted` |
| Body | Golos Text 400 | 17px | 1.65 |
| Small | Golos Text 400 | 15px | 1.5 |
| Kicker / метка | Manrope 500 | 12–13px, uppercase | `letter-spacing: .14em` |
| Caption под фото | Golos Text 400 | 13px | `--c-text-soft` |

Заголовки — только Manrope; не смешиваем два шрифта внутри одного заголовка.
Максимальная длина строки текста — 68 символов (`max-width: 62ch` для абзацев).

## 5. Сетка, ритм, формы

- Контейнер: `max-width 1240px`, боковые отступы `clamp(20px, 5vw, 40px)`.
- Сетка: 12 колонок, желоб 24px (мобильный — 16px).
- Вертикальный ритм секций: `clamp(64px, 8vw, 128px)`; между заголовком и текстом — 20–24px.
- Базовый шаг отступов — 4px: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96.
- Радиусы: 4px (мелкие метки), 10px (кнопки, поля), 18px (карточки), 999px (чипы).
- Тени: один токен `0 24px 64px -36px rgba(23,59,54,.35)` — только для «парящих» панелей (панель поиска, диалог).
  В остальных местах — разделитель `1px --c-line` вместо тени.
- Асимметрия: в hero сетка `7 / 5` колонок, портрет «внахлёст» по верхнему левому углу рамки с фото;
  в блоке «О Ксении» фото занимает колонки 1–5, текст начинается с 7-й.

## 6. Фотографии и арт-дирекшн

- Палитра съёмки: молочные стены, светлое дерево, зелень, мягкий дневной свет. Без «риэлторского» пересвета и HDR.
- Пропорции: hero 16:9, карточка объекта 4:3, портрет 4:5, обложка статьи 3:2.
- Всегда указываем `width`/`height` и `loading="lazy"` (кроме hero — `fetchpriority="high"`), чтобы не было сдвигов вёрстки.
- Alt-текст описывает **объект**: «Гостиная с панорамными окнами, светлая мебель, вид на двор», а не «фото 1».
- В прототипе вместо фото — SVG-заглушки в палитре сайта с подписью «демонстрационное изображение».
  **Портрет Ксении не генерируется**: ставится силуэт-заглушка и подпись «Фото Ксении будет добавлено»
  (в `title` SVG — «Место для фотографии Ксении Хазиевой»).

## 7. Иллюстрации

Тонкая линейная графика, штрих 1.5–2px, только `--c-green-800` (контур) и `--c-terracotta` (один смысловой акцент:
галочка, ключ, печать). Никаких заливок и градиентов. Набор иконок-сцен 96×96: документы+лупа, галочка-проверка,
два человека за столом, договор+ручка, дом+щит, ключи, план квартиры, дом с табличкой продажи, карта-метка, печать.
Все иконки — один авторский набор, без микса Font Awesome / Heroicons / Flaticon.

## 8. Движение

- Длительности: 160ms (hover), 240ms (появление), 420ms (раскрытие панели). easing `cubic-bezier(.22,.61,.36,1)`.
- Появление секций: `opacity 0 → 1`, `translateY 12px → 0`, один раз, `IntersectionObserver`, порог 0.15.
- Переходы между страницами (в продакшене, Next.js): 180ms fade контента, хедер остаётся.
- Уважаем `prefers-reduced-motion: reduce` — анимации отключаются, состояния меняются мгновенно.
- Запрещено: бесконечные автослайдеры, параллакс на мобильных, анимация при каждом скролле.

## 9. Доступность

- Минимальная область нажатия 44×44px; на мобильных основные кнопки — на всю ширину блока.
- Видимый фокус: `outline: 2px solid var(--c-terracotta-ink); outline-offset: 2px;` — не убираем никогда.
- Все поля связаны с `<label>`; ошибки выводятся текстом рядом с полем и дублируются `aria-live="polite"`.
- Ровно один `<h1>` на страницу, иерархия H1→H2→H3 без пропусков.
- Семантика: `header/nav/main/section/article/footer`, `aria-expanded` для меню и аккордеонов,
  `aria-current="page"` для активного пункта навигации.
- Контраст: текст не ниже 4.5:1, крупные заголовки — не ниже 3:1.

## 10. Тон текста

**Можно:** «помогу разобраться», «проверю документы и покажу, на что обратить внимание»,
«на каждом этапе вы понимаете, что происходит дальше», «при необходимости рекомендую профильного юриста».

**Нельзя:** «лучший риэлтор Екатеринбурга», «гарантирую 100% юридическую чистоту», «продам за 3 дня»,
«без рисков», любые цифры опыта и количества сделок без подтверждения, фальшивые отзывы и рейтинги.

Разграничение ответственности проговаривается в текстах: риэлтор организует и сопровождает процесс,
юридические заключения при необходимости даёт юрист.

## 11. Состояния компонентов (обязательный минимум)

| Компонент | Состояния |
| --- | --- |
| Кнопка | default / hover / active / focus-visible / disabled / loading |
| Поле ввода | default / focus / filled / error (+текст) / disabled / readonly |
| Карточка объекта | default / hover (подъём 2px + подчёркивание цены) / «продано» (фото 60% + плашка) / скелетон |
| Фильтр | свёрнут / активен (терракотовая метка) / «нет результатов» |
| Статусы объявлений | черновик, на проверке, опубликовано, отклонено, продано, снято — цвет + текст, не только цвет |
| Список | загрузка / пусто / ошибка с повтором |
| Форма | idle / validating / error / success / demo (прототип) |

## 12. Мобильная версия

- Хедер: лого + кнопка-бургер (44×44) + «Связаться». Меню — полноэкранная панель с крупными пунктами (мин. 52px).
- Фильтры каталога — кнопка «Фильтры (2)» снизу, открывает нижнюю панель с прокруткой внутри.
- Карточки объектов — одна колонка; галерея объекта — свайп с точками-индикаторами и счётчиком «3 / 12».
- Формы — один столбец, `inputmode="tel"` / `numeric`, автозаполнение; при длинной форме кнопка фиксируется внизу.
- Горизонтальный скролл не допускается: длинные строки переносятся, таблицы получают свой скролл-контейнер.

## 13. Логотип и айдентика

- Текстовый знак: «КСЕНИЯ ХАЗИЕВА» — Manrope 600, uppercase, `letter-spacing: .08em`, 15px в хедере / 18px в футере.
- Монограмма «КХ» в тонком круге `--c-green-800` — фавикон и штамп на документах/бланках.
- Вторая строка подписи: «Специалист по недвижимости» — Golos Text 400, 12px, `--c-text-muted`.
- Терракотовая точка после монограммы — единственный «декоративный» элемент бренда; повторяется в нумерации этапов.
